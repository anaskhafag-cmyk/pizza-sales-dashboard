# 🍕 pizza-sales-dashboard
An interactive Excel sales analytics dashboard tracking order trends, top-selling items, revenue distribution, and pricing performance using custom data slicers and visual KPIs.

An interactive analytical dashboard built to track key sales metrics, order distributions, product trends, and pricing performance for a pizza restaurant dataset.

## Key Metrics (KPIs)
* **Total Sales:** $8,436
* **Total Quantity Sold:** 511 units
* **Total Orders:** 499 orders

## Features & Visualizations

1. **Total Sales per Category:**
   * **Classic:** 30%
   * **Supreme:** 27%
   * **Veggie:** 24%
   * **Chicken:** 19%

2. **Sales Distribution by Pizza Size:**
   * **Large (L):** 48% (Leading size)
   * **Medium (M):** 27%
   * **Small (S):** 22%
   * **Extra Large (XL):** 3%

3. **Hourly Order Trend:**
   * Tracks order volume from 11:00 AM to 11:00 PM.
   * Peak order time occurs at **5:00 PM** (72 orders), followed by lunch hours at **12:00 PM – 1:00 PM** (55–56 orders).

4. **Top 10 Best-Selling Pizzas (by volume):**
   * **The Classic Deluxe Pizza:** 30 orders (Top seller)
   * **The Pepperoni Pizza:** 26 orders
   * **The Four Cheese Pizza:** 23 orders
   * **The Sicilian Pizza & The Thai Chicken Pizza:** 22 orders each

5. **Top 5 Most Expensive Pizzas:**
   * **The Classic Deluxe Pizza:** $459 total value
   * **The Thai Chicken Pizza:** $429
   * **The Greek Pizza:** $402
   * **The Four Cheese Pizza:** $400
   * **The Barbecue Chicken Pizza:** $342

6. **Interactive Slicers & Filters:**
   * Filter dashboard visuals by **Pizza Size** (`L`, `M`, `S`, `XL`).
   * Filter by **Pizza Category** (`Chicken`, `Classic`, `Supreme`, `Veggie`).
   * Time frame filtering via **Order Date Timeline / Slicer**.

## Tools Used
* **Microsoft Excel** (Data Visualization, Pivot Tables, Slicers, Dashboard Design)
